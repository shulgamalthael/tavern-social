The trend chart reuses the main dashboard's existing `bucketByDay`/`DailyBarChart` (the latter extracted into its own shared file specifically for this reuse) — confirmed live the extraction didn't regress the original dashboard.

**Left as deliberate v2 scope, named rather than silently dropped**: a real second-price/Vickrey auction (v1 is honest highest-bid-wins, not a live multi-bidder auction), topping up a paused campaign's budget from the admin panel (paused is currently a terminal, read-only state — needs a payment-ledger sub-table to do properly, a real design decision), a standalone restricted-category/age/region rule engine (the existing `BusinessCategory` taxonomy has no category worth banning today — inventing one without real policy behind it would be guessing), and CDN/edge caching for ad creative images (none exists in the project at all today for any media — a project-wide infra choice, not an ads-specific one). Per-campaign analytics breakdowns (beyond the platform-wide totals/trend chart that now exist) remain a real, separate follow-up if the current view turns out not to be enough.

Video creatives — the one item from that list that was pure mechanics, not a policy call — were closed in §68.6: `AdFormat` gained `video` (additive migration, one nullable `videoUrl` column), allowed only in the `content`/`in_feed` placements (too small physically elsewhere), rendered as a real muted-autoplay `<video>` inside the same fixed CLS-safe box every other format uses. Live-verified: a real video creative round-robins correctly against an image creative in the same pool, and a live Chromium pass confirmed the `<video>` element genuinely plays, is genuinely muted, and stays within the reserved box size.

**A real blind spot this section itself never named**: none of §68–§68.9 ever tracked "does the advertiser have a frontend at all" as an open item — every verification pass exercised the backend directly (REST calls, DB rows) or the *admin*/*publisher* side, never the owner's own dashboard. The owner caught this directly by asking. Closed in §70: a full "Реклама" tab in the Business Dashboard, plus one small backend gap §70 found while building it (no image-upload endpoint existed yet for ad creatives at all).
